Developer guide

Wavecrest Swimming Academy — Documentation

Use this guide to install, customize and prepare the static HTML template for a production integration.

1. Installation

Extract the project and open the root index.html in a modern browser. A local static server is recommended. The template uses Bootstrap 5.3.3, Lucide and Google Fonts via CDN.

2. Page architecture

The root contains public pages. The member-dashboard folder contains swimmer-facing pages. The admin-dashboard folder contains academy operations pages. Their scripts and styles are separated to preserve distinct workflows.

3. Content and data

Edit assets/js/data.js for public programmes, coaches, timetable samples and journal entries. Replace all sample prices, dates, names, contact details, testimonials and facility information before publication.

4. Brand colors and typography

Change the custom properties at the top of assets/css/style.css. The approved palette is Deep Navy #063B5C, Ocean Blue #087EAA and Aqua Turquoise #35C6D9. Keep Sora and Inter as the two font families.

5. Dark mode and RTL

Theme and layout direction toggles are included on the public site and both dashboards. Preferences are stored in localStorage. Verify all forms, tables, menus and dashboard sidebars in both directions.

6. Booking workflow

The multi-step form validates the current step and saves a sample request in browser storage before showing the confirmation page. Connect a backend to validate availability, reserve seats, create enrolments and send emails.

7. Member portal

The member portal demonstrates a personal learning journey: enrolment, schedule, attendance, coach-assessed progression, fees, messages and profile settings. Sample progress is not automatically measured.

8. Admin workspace

The admin workspace includes sample management tables and local add/edit/remove actions. These local changes are not shared across users or devices. Replace with authenticated APIs and role-based authorization.

9. Payments and authentication

Use a secure server-side authentication and payment implementation. Never store passwords, payment credentials, secret keys or sensitive member data in static files or localStorage.

10. Contact, newsletter and maps

Connect form submission services, mailing integrations and a verified map embed. The current contact form only displays local feedback.

11. Images and credits

Replace remote sample imagery with licensed, optimized academy photography. Use meaningful alt text and confirm image/guardian permissions for minors.

12. Production QA

Test every public and dashboard page in Chrome, Firefox, Safari and Edge at mobile, tablet, desktop and large desktop widths. Check keyboard navigation, contrast, reduced motion, broken links, console errors, form validation and no horizontal overflow.
